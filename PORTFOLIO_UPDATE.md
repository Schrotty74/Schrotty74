# Portfolio update rule

The GitHub profile and the Schrotty74 portfolio are separate public entry
points. Check both when a featured project is added, removed, renamed, or its
visitor-facing description, repository URL, public app URL, supported platform,
or portfolio detail page changes.

For a new public project:

1. Verify that its repository and public information are ready to link.
2. Add matching English and German portfolio cards and detail pages.
3. Add the project to the profile README only when it belongs among the
   selected featured projects.
4. Use only public assets and synthetic demo data in portfolio material.

Internal refactors, local testing, and unchanged release metadata do not by
themselves require an update. Never publish personal data, exports, logs,
backups, licence keys, tokens, local paths, or screenshots with real user data.
