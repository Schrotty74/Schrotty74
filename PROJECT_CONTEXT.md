the community link, and the public principles page. It contains no app source
code, build process, package manager, or runtime dependencies.

## Start here

Before changing the profile, read this file, `NEXT_STEPS.md`, `README.md`, and
`PORTFOLIO_UPDATE.md`. Check the affected public repository and portfolio page
before claiming a project, URL, platform, or release status has changed.

## Rules

- Keep only verified, public information in the profile.
- Use the public name `Schrotty74` only; never publish private paths, personal
  data, exports, logs, credentials, tokens, backups, or private screenshots.
- Keep project names, descriptions, and URLs factual and concise.
- A profile update does not authorize commits, pushes, tags, releases, or
  changes to linked projects.
- Update this file and `NEXT_STEPS.md` when the maintained profile scope or an
  actual open task changes.
